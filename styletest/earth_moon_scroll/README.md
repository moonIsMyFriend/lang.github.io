# Earth → Moon 

---

## 프로젝트 구조 (모듈 분리)

| 모듈 | 파일 | 역할 |
|------|------|------|
| **background** | `background.css` | 우주 배경, 스크롤 레이아웃, 별, 달(2·3페이지), 거리 텍스트, 라벨 |
| **earth** | `earth.css`, `earth.js` | 지구 3D 씬, `EarthIntroRocket` (아래→위→턴→오른쪽 3D 궤적) |
| **rocket** | `rocket.css`, `rocket.js` | DOM 로켓 위치·비행·대기·모드 |
| **line** | `line.css`, `line.js` | 주황색 궤적(트레일) 포인트·렌더·freeze |
| **scroll** | `scroll.js` | 페이지 스크롤, 인트로/달 시퀀스 연결 (오케스트레이션) |

진입 HTML: `styletest/index.html`  
빌드: `node build_publish.js` → `publish/`

## 페이지별 의도 (3화면)

| 페이지 | 화면 | 로켓·궤적 의도 |
|--------|------|----------------|
| **1** | 지구 (EARTH) | 3D 지구가 자전. 사용자가 처음 입장할 때는 자동으로 로켓이 궤적을 그리며 이동. 자동이동은 로켓이 지구 아래에서 나타나서 위로 올라가고 왼쪽 중앙부분으로 이동하고  **2페이지 방향(오른쪽)**으로 이동. 도착지는 2페이지 중심|
| **2** | 384,400km (DISTANCE) | 사용자가 처음으로 2페이지에 입장하면 로켓은 **화면 중앙(50vw, 44vh)** 에서 대기 → 잠시 후 **오른쪽(3페이지 방향)** 자동 출발. 1페이지 궤적 제거|
| **3** | 달 (MOON) | 왼쪽 대기 → 달 쪽 비행 → 달 주위를 둥글게 돌면서 궤도를 그림 → 착륙. 1·2페이지 궤적은 제거. |

## 공통
- 3번째 페이지 이동하기 전까지는 이전 페이지는 **다시 왼쪽으로 돌아갈 수 없음** (forward-only).
- 모든 로켓의 이동은 궤적을 그리며 궤적은 서서히 사라진다.
