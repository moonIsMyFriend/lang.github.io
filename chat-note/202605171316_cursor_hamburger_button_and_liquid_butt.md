**Cursor**

액체 느낌을 강화하고, 색상 효과가 버튼 영역 밖으로 나가지 않도록 수정합니다.


액체 효과를 강화하고 `overflow: hidden`으로 색상이 버튼 밖으로 나가지 않게 구조를 조정합니다.


SVG goo 필터가 경계 밖으로 번지는 문제를 `contain`과 `clip-path`로 더 확실히 막습니다.


액체 느낌과 영역 제한을 개선했습니다.

### 변경 사항

1. **액체감 강화**
   - blob 3개로 늘려 서로 합쳐지는 goo 효과 강화
   - goo 필터 블러·농도 상향 (`stdDeviation 14`, alpha 32)
   - idle 상태에서 blob이 천천히 흔들리는 `liquid-drift` 애니메이션
   - 호버 시 액체 움직임이 빨라지고, 라벨 위로 빛이 스치는 shine 효과

2. **버튼 영역 밖으로 색이 안 나가게**
   - `.liquid-btn`에 `overflow: hidden`, `clip-path`, `contain: paint` 적용
   - 액체 전용 `.liquid-btn__liquid` 레이어로 이중 클리핑
   - blob·glow를 버튼 `inset` 안에만 배치 (이전 `-8px` 여백 제거)
   - dot 외부 glow 제거 → `inset` 그림자만 사용

3. **버튼별 색 조합** — profile / research / mission 등 메뉴마다 다른 그라데이션 톤

메뉴를 열어 버튼 안에서만 색이 움직이는지, blob이 서로 붙어 흐르는지 확인해 보시면 됩니다. 더 진한 액체감이나 특정 색 톤 조정이 필요하면 말씀해 주세요.

### 수정 파일
- `earth_to_moon.html` — 힌트를 클릭 가능한 `button`으로 변경, 왼쪽 힌트 추가
